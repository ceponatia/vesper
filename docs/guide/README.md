# Vesper guide

Task-oriented manual pages: how to *use* Vesper, page by page. The system docs one level up explain how it works inside; these explain what to click and what to expect. Written for the developer-operator for now — they reference internals freely; end-user polish comes later.

| Page | Flow |
| --- | --- |
| [creating-characters.md](creating-characters.md) | Forge or hand-build a character, attributes, outfit, portraits |
| [creating-items.md](creating-items.md) | Clothing/object/container items, categories, coverage |
| [locations.md](locations.md) | Places, ambient, scale, area, the connection graph |
| [building-worlds.md](building-worlds.md) | Forge a world from a premise, edit, save, manage cast |
| [social-cards.md](social-cards.md) | Taboos & social rules: severity, triggers, tag flips, reuse |
| [running-sessions.md](running-sessions.md) | Start, play, and delete sessions |

Pages get added as flows stabilize; if you hit a flow with no page, that's a gap worth filing.
